# Classifier determinism — measured, not assumed

Generated by `clay/determinism_check.mjs`. 3 identical requests per classifier,
fact set `tests/golden/facts/akuvo.json`, model `gpt-5.6-sol`, `seed: 0`,
no `temperature` (the GPT-5.6 family rejects `temperature: 0` with HTTP 400).

`value` and `confidence` are what the score is computed from. `evidence` is prose:
it is worth knowing when it moves, but it does not change a grade.

| Component | value | confidence | evidence | values seen |
|---|---|---|---|---|
| `industry_vertical` | stable | stable | stable | "FinTech" |
| `stage_maturity` | stable | **drifted** | drifted | 3 |
| `company_type` | stable | stable | stable | 10 |
| `geography` | stable | stable | stable | 10 |
| `revenue_range` | stable | stable | stable | 10 |
| `activation_state` | stable | stable | drifted | "Accelerating" |
| `buying_signal` | stable | stable | drifted | 7 |

**7 of 7** classifiers returned an identical `value` across 3 runs;
**6 of 7** returned an identical `confidence`.

At least one scoring input moved between byte-identical requests, so a score on this fact set is not reproducible. This is the cost of `temperature: 0` being unavailable and it should be stated to anyone relying on a grade.
