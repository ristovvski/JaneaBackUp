# Chat history

**[RULINGS_AND_INSTRUCTIONS.md](RULINGS_AND_INSTRUCTIONS.md)** — every human instruction given to the
working sessions that built this estate, chronological and verbatim (pseudonymized). This is the
decision record: when a rule is disputed, it settles what was actually asked for, and when.

The raw session transcripts that used to sit in `sessions/` are **removed from the current tree**.
They were bulk person data by nature — every prospect ever discussed, in context, with company and
title — and pseudonymizing names inside them still left them re-identifiable.

**They are still in the git history** (every commit before the 2026-09-24 scrub). The history rewrite
that removes them is postponed until branch cleanup and a verified backup bundle; until it has run,
anyone who can clone this repository can read them. See SECURITY.md.
