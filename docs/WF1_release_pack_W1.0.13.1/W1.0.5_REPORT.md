## ⚠️ Post-acceptance finding — sent-path `Create Activity` empty-note 400 (PRE-EXISTING, not a W1.0.5 regression)
Investigating double execs **9992 (LA-sent)** and **9995 (LB-sent)** — these were the *only* LA/LB sent runs (NOT re-fires). Both errored at `Create Activity`:
```
HTTP 400 NodeApiError — "Validation failed: note: This value is too short. It should have 1 character or more."
body: { subject:"LinkedIn invite sent — L105", type:"linkedin_messaging", done:true, participants:[…], owner_id:16340280, note:"", lead_id:… }
```
- **Root cause:** builder does `note: n.invite || ''`; `n.invite` maps from the HeyReach `connection_message`. My LA/LB double fires omitted `connection_message` → `note:""` → Pipedrive v2 `POST /activities` rejects empty note.
- **Why prod 9999 passed:** the prod fire set `connection_message="final invite"` → `note:"final invite"` (confirmed on activity 40944) → 200. The passing prod run **masked** the bug; the double **exposed** it.
- **Scope:** the SENT path only. Org/Person/Lead all created *before* `Create Activity`, so they persist; only the "invite sent" timeline activity is lost and the sent execution ends in `error` (fires the error-workflow → WF-ERR Slack). W1.0.5 changed only `M7 Build` + `M7 Slack Warn` on the REPLY path — **not** this node. Pre-existing since the activity was introduced.
- **Production relevance: HIGH.** Real LinkedIn connection requests are frequently sent with no note → this 400s on those events today.
- **Sibling audit:** `M7 Reply Activity` (reply path) has the same shape — `note: reply_text` (and it is *still inline*, not Code-built) → same 400 if a reply's text is empty. `M8 Task` has no `note` field (safe).
- **Correction to LA verdict below:** LA's W1.0.5 PASS is valid *for the reply-path link format* (measured on LA-reply, which found the pre-created lead). But LA-**sent** errored — I should have checked the sent exec status and did not. Fix scoped to **W1.0.6** (omit `note` when empty — same idiom as F13 org_id / R4 empty custom fields; apply to `Create Activity` and `M7 Reply Activity`).
