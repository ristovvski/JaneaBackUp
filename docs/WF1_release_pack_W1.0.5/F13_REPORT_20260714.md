# F13 — Code-built lead/activity bodies (fix for E1 + E2), deployed & live-verified + Lule backfill

**Date:** 2026-07-14. **Root cause fixed:** `Create Lead` inline-field JSON template rendered invalid JSON when `organization_id` was null (no company) → node threw before the POST → no lead → all lead-bound writes died. Two production incidents (E1 Lule sent-error; E2 same on the full happy path).

## Fix (implemented — Code-built idiom, not the inline `?? null` patch)
Converted the **two** remaining inline-field `jsonBody` nodes to the established Code-built idiom (build a JS object, `JSON.stringify`), matching `Person Create` / `M6 Build`:
- **`Create Lead`** — builds the body in an IIFE; **omits `organization_id` entirely when null**; always `label_ids:[cold]`, `channel:578` (number), `channel_id` from CONFIG; clean title (no `" — null"`).
- **`Create Activity`** — same idiom; guarded `lead_id`.

Audit of **every** `httpRequest jsonBody` in WF-1: only these two used the fragile inline-field pattern; all others already `JSON.stringify` a whole object or use an IIFE. After F13, **zero** inline-field-template bodies remain (asserted by a static test).

Release: **W1.0.2** (`patch_wf1_w102.py`, deterministic W1.0.1→W1.0.2, byte-verified). Git commit `F13` (audit bundle now 17 commits; 1-file, 2-line diff).

## Regression tests added
1. **Static** (`wf1_static_contract_tests.js`, now 28 tests): `Create Lead` renders **valid JSON with `organization_id` OMITTED when null** (+ cold/channel/channel_id present, clean title), org included when present; `Create Activity` valid JSON; and "no `httpRequest` jsonBody uses a bare inline `{{ }}` field." These 3 **fail on W1.0.1 (25/28) and pass on W1.0.2 (28/28)** — i.e. they would have caught E1/E2.
2. **Live**: empty-/no-company person driven through sent→accepted→reply (below).

### Why the canary/live-suite missed it
Every prior fixture (Person-5e07d3f5, T1, HR Test) had a **non-empty `company_name`** → org created → `organization_id` non-null → valid JSON. Real organic leads frequently have **no company** (Lule). Fixture shape ≠ real tenant payload.
