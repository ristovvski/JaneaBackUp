## Parser diff (what changed)
- **Normalize** - new parser -> `n.event_trio {marker, event_name, hypothesis, skip, warn_text}`:
  - marker = campaign.name CONTAINS a `[...]` group (case-insensitive, tolerant).
  - hypothesis = `CONFIG.event_marker_canon[bracket-lowercased]` (unknown bracket -> null, not written).
  - event_name = campaign.name minus the bracket group, trimmed of whitespace + leading/trailing `-`.
  - guardrail: empty tail / second bracket / >60 chars -> skip + warn_text.
  - no marker -> fully inert.
- **CONFIG** += `fields.person_event_name` (ab5540d2), `fields.person_hypothesis` (8bdae1a9), `event_marker_canon = {"events visiting":"Events Visiting"}`.
- **Writes** (marker+!skip, ALWAYS-OVERWRITE-on-differ = last-touch, idempotent; Medium unchanged): Person Create + Person Patch Invited + M5 Person Patch Accepted, + their gates (IF Rank Allows Invited, M5 IF Rank Accepted).
- **+2 nodes** as a NON-BLOCKING TEE off Normalize (Normalize->Switch UNCHANGED): `IF Event Marker Bad` (skip===true) -> `Event Marker Warn` (Slack -> slack_channel_ops, text = warn_text). 8th Slack node.
- **UNCHANGED:** selectLead / lead title / lead Campaign field - the full bracketed campaign.name flows through as-is; campaign-match is exact-string (bracket-safe, asserted).

Deterministic patcher (`patch_wf1_w1013.py`), byte-identical re-run. Parser executed against all 9 spec cases before tests (canonical dash/no-dash/case-drift, unknown bracket, no-marker inert, 3 guardrails, E-1 form) - all correct.
